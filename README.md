# Introduction 
This is the Github Repository for paper *Improving Phenotype Clustering in Multivariate Phenome-wide Association Studies and the Study of Pleiotropic Effects of Susceptible Genes of Lung and Prostate Cancers*

## 1 code
### 1.1 `functions.R`: functions used in power analysis.

#### 1.1.1 `lambdas_setup()`
This function generate effect size corresponding to paper descriptions
```r
lambdas_setup(beta, scene, K)
```
##### Arguments
- beta: control the effect size
- scene: six scenes referring to the paper
- K: total number of phenotypes
##### Values
effect sizes organized by category, where each category $m$ has a vector of length $k_m$:
```math
\{ \lambda_{11}, \ldots, \lambda_{1k_1} \}, \{ \lambda_{21}, \ldots, \lambda_{2k_2} \}, \ldots, \{ \lambda_{M1}, \ldots, \lambda_{Mk_M} \}
```

####  1.1.2 `simulation()`
This function generates simulated phenotypic data and a genetic variant. It is designed for method comparison in this paper.
```r
simulation(n, MAF, lambda, rho_a, rho_w, c, seed = NA)
```
##### Arguments
- n: sample size
- MAF: minor allele frequency
- lambda: $\{ \lambda_{11}, \ldots, \lambda_{1k_1} \}, \{ \lambda_{21}, \ldots, \lambda_{2k_2} \}, \ldots, \{ \lambda_{M1}, \ldots, \lambda_{Mk_M} \}$ effect size for each category, could be generate by `lambdas_setup(beta, scene, K)` function
- rho_a: control correlation across phenotypic categoris
- rho_w: controls the correlation among phenotypes within each category
- c: constant sqrt(c2)
- seed: optional
##### Values
Returns a list containing:
- y: phenotypes
- x: genotypes, {0, 1, 2}
- cat: information of categories based on lambda

####  1.1.3 `KCLC`
```r
Kmeans.clusters <- kmeans_Silhouette(y, cat)
KCLC.P <- CLC(y, x, Kmeans.clusters, cat)
```
`kmeans_Silhouette()` will generate the optimal clusters decision for phenotypes in each category using kmeans method based on Silhouette scores.

`CLC()` will test the association between each category and genotype based on clusters.

##### Arguments
- y: phenotypes, could be generated by `simulation()`
- x: genotype, could be generated by `simulation()`
- cat: information of categories, self-defined, also could be generated by `simulation()` based on `lambda` variable

####  1.1.4 `HCLC`
```r
HCM.clusters <- HCM(y, cat)
HCLC.P <- CLC(y, x, HCM.clusters, cat)
```
`HCM()` will generate the optimal clusters decision for phenotypes in each category using Hierarchical Clustering Method.
`CLC()` will test the association between each category and genotype based on clusters.

##### Arguments
- y: phenotypes, could be generated by `simulation()`
- x: genotype, could be generated by `simulation()`
- cat: information of categories, self-defined, also could be generated by `simulation()` based on `lambda` variable

#### 1.1.5 `MANOVA`, `multiPhen`, `TATES`
```r
MANOVA.P <- MANOVA.test(y, x, cat)
multiPhen.P <- multiphen.test(y, x, cat)
TATES.P <- TATES.test(y, x, cat)
```
##### Arguments
- y: phenotypes, could be generated by `simulation()`
- x: genotype, could be generated by `simulation()`
- cat: information of categories, self-defined, also could be generated by `simulation()` based on `lambda` variable

#### 1.1.6 FDR control using FC method
```r
t <- T_estimation(P, alpha)
```
will estimate a threshold for P value targeting to FDP level of alpha
##### Arguments
- P: a list of P values from multiple testing
- alpha: targeting FDP level

### 1.2 `script.R`: reproduce the simulation results
run the following command in terminal to reproduce the results referring to the paper. `plz ensuring that functions.R is downloaded in the same folder`
```bash
Rscript --vanilla script.R -e 8888 -s 6 -r 200 -K 1000 -n 2000 -b 0.13 -f 0.3 -a 0.2 -w 0.3 -c 0.5 -A 0.05
```
- `-e`: seed (default = NA)
- `-s`: Scene number (1-6) (default = 1)
- `-r`: replicates number (default = 200)
- `-K`: total number of phenotypes (default = 1000)
- `-n`: sample size (default = 2000)
- `-b`: beta controling the effect size (default = 0.005)
- `-f`: minor allel frequency (default = 0.3)
- `-a`: $\rho_a$ controling correlation across phenotypic categories (default = 0.2)
- `-w`: $\rho_w$ controling the correlation among phenotypes within each category (default = 0.3)
- `-c`: $c^2$ a constant value (default = 0.5)
- `-A`: targeting FDP level (default = 0.05)
